# Building the Toybox Input Recorder

The first goal for **Toybox** was to capture repeatable gameplay input so bugs can be replayed quickly.

## What shipped

- Command stream capture with frame timestamps
- Keyboard + gamepad support
- Export to JSON snapshots

## Next step

I am wiring this into a comparison viewer described in [DevLog2](DevLog2.md).
